# Contribution Guidelines

- One pull request per suggestion. Search the list first to avoid duplicates.
- Format: `- [Name](https://link) - Short, neutral description ending with a period.`
- Put official .gov sources first within a section.
- Resources must be useful to small businesses doing U.S. federal contracting and the link must work.
- No affiliate links, link shorteners, or marketing language. Commercial tools are welcome with an honest one-line description; do not state prices (they change).
- Vendors may add their own product once, and must say so in the PR.
- Keep descriptions under about 150 characters.
